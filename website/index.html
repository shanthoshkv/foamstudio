FoamStudio is a desktop workbench for OpenFOAM. It installs the solver, writes the case, runs it, plots convergence while it runs, and checks the result against published data.

The whole loop, in one window

The same seven steps every CFD job takes. FoamStudio does each one for you, shows the exact command it ran, and leaves you an ordinary OpenFOAM case you can open in a terminal at any point.

  1. InstallSets up WSL and OpenFOAM, or finds the one you have.
  2. CasePick a solver; every dictionary is written for you.
  3. GeometrySTL, OBJ, STEP, Gmsh, Fluent or any NACA section.
  4. MeshblockMesh or snappyHexMesh, sized from the y+ you want.
  5. RunSerial or MPI; keeps going if you close the app.
  6. MonitorResiduals, Cl and Cd live; stops when converged.
  7. ReportFields, streamlines, probes and an HTML or PDF report.

Meshes built for the wall

The airfoil template builds a 12-block C-mesh with a wall layer grown along the surface normal. Cells stay square to the wall, where the physics is hardest.

A thin window over a core you can script

The case generator is the only thing that writes OpenFOAM dictionaries, so the window, the command line and CI produce byte-identical cases. WSL commands run as LF scripts inside the case, so no $ ever reaches wsl.exe, and Stop ends the whole Linux process group rather than only the Windows wrapper.

Ten CI jobs on Windows, macOS and Linux run on every push, including a real solver run and an 85-step scripted walk through the GUI, with pip-audit, an SBOM, CodeQL and an 87% coverage gate on the core.

Install

Windows, Linux or macOS. The installer ships Python and every library; OpenFOAM is set up on first launch.

  1. Download the installer

    Windows: FoamStudio-0.9.0-win64.exe from the releases page. No admin rights needed.

  2. Choose how OpenFOAM is installed

    Automatic sets up Ubuntu 24.04 in WSL and OpenFOAM v2412. Already have one? Pick it from the Runtimes tab, or add an SSH machine.

  3. Run the demo

    The lid-driven cavity runs in about a minute and proves the whole chain works.

From source

git clone https://github.com/shanthoshkv/foamstudio
cd foamstudio
python launch.py

From a terminal

foamstudio --detect-runtimes > rt.json
foamstudio --airfoil 2412 --alpha 4 --re 3e6 --project wing
foamstudio --project wing --runtime rt.json --run-case
foamstudio --project wing --report wing.html

Where it stands

Version 0.9. Working and tested; not yet a signed 1.0.

Known gaps

  • Airfoil lift at 10° is 4.7% above Ladson's band.
  • Step reattachment passes by a small margin, on one mesh family.
  • Planar 2D nozzle vs 1-D theory stays a model-form miss; the axisymmetric nozzle now passes to 0.03%.
  • Some Foundation 14 templates (XiFoam, CHT, compressibleInterFoam) still fail.
