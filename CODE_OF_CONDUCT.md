# Code of conduct

People working on FoamStudio treat each other with respect. That covers issues, reviews, discussions, and chat.

## Expected

- Critique the code and the decision, and keep the person intact.
- Assume a question is asked in good faith.
- Give the command, the log tail, and a suggested fix when something fails. Hidden failures waste the next person's time.

## Not accepted

- Harassment, slurs, or sexual comments.
- Publishing someone's private information.
- Using the project to attack people or to ship malware.

## Reports

Report conduct problems to the maintainers through a private channel listed on the project page, not in a public issue. Maintainers will say what they did, within the limits of privacy.

This text is the project's own short policy. It is not the Contributor Covenant.
